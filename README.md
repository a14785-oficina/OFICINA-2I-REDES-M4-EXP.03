# Exercício 03

Página de apresentação com estilos CSS, classes reutilizáveis e seleção por ID para destaques visuais.

## Conteúdo
- Cabeçalho principal
- Listas de competências e soft skills
- Seção de hobbies e contactos
- Estilos internos e referências externas ao Google Fonts
- Uso de classes e seletores por ID

## Como visualizar
1. Abrir `index.html` no navegador.
2. Confirmar que o ficheiro `estilo.css` e a imagem `Designer.png` se encontram na mesma pasta.

## Objetivo
Explorar CSS em páginas estáticas, incluindo diferentes níveis de especificidade e organização visual.
